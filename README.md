# Welcome to LoL Esports Replay Player

Because the native replay player of [LoL Esports](https://lolesports.com) sucks and watching replays directly on YouTube often leads to spoilers, this project provides a dedicated replay player designed for a spoiler-free experience.

---

## Features

- **No UI Cutoffs:** Pick & Ban (BP) and champion status won't be cut off.
- **Spoiler-Free:** Never get spoiled by the video length or progress bar.
- **Immersive:** Delivers a clean, livestream-like viewing experience.

---

## Getting Started

1. Open the player in your browser.
2. Enter the match's YouTube URL into the input field.
3. Click **Replay the Match** to start.

### How to Copy Replay URLs Without Spoilers

1. Go to [LoL Esports](https://lolesports.com) and open the desired replay.
2. Make sure the video is streaming from YouTube.
3. Start playback, right-click the video title, and copy the URL.

## User Guide

### Keyboard Controls

| Key | Action |
| :--- | :--- |
| `Space` | Play / Pause |
| `Arrow Left` / `Arrow Right` | Rewind / Fast-Forward 10 seconds |
| `Arrow Up` / `Arrow Down` | Volume Up / Down |
| `f` | Fast-Forward 5 minutes (skip breaks between games) |
| `Shift` + `f` | Fast-Forward 1 hour (skip to next match) |
| `r` | Rewind 5 minutes |
| `Shift` + `r` |  Rewind 1 hour |

> **Tips:**
> - If keyboard controls do not respond, click inside the player window to focus.
> - For the best experience, ensure the browser tab is in full-screen mode (similar to native YouTube full screen).
